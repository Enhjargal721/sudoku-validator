# Олон урсгалт Sudoku шалгах програм

## Төслийн зорилго

Энэхүү төсөл нь Үйлдлийн системийн хичээлийн хүрээнд C хэл болон POSIX Threads (`pthread`) ашиглан 9×9 хэмжээтэй Sudoku шийдлийг шалгах програм юм.

Програм нь нийт **11 thread (урсгал)** ашиглана:

- 1 урсгал — Sudoku-ийн 9 мөрийг шалгана.
- 1 урсгал — Sudoku-ийн 9 баганыг шалгана.
- 9 урсгал — тус бүр нэг 3×3 дэд хүснэгтийг шалгана.

## Үндсэн боломжууд

- Хэрэглэгчээс 9×9 Sudoku-ийн тоон өгөгдөл авна.
- Мөр, багана болон 3×3 дэд хүснэгтүүдийг шалгана.
- Шалгалтын үр дүнг `PASS` эсвэл `FAIL` гэж харуулна.
- Эцсийн үр дүнг `VALID` эсвэл `INVALID` гэж харуулна.
- Хэрэглэгч дахин Sudoku шалгах боломжтой.

## Шаардлагатай орчин

- GCC C хөрвүүлэгч
- POSIX Threads (`pthread`)
- Windows үйлдлийн систем дээр MSYS2 UCRT64 орчин

## Програмыг ажиллуулах

MSYS2 UCRT64 терминалыг нээгээд дараах командуудыг ажиллуулна:

```bash
cd /c/OS-BD1/sudoku-validator
gcc main.c -o sudoku_validator.exe -pthread
./sudoku_validator.exe
```

## Ашиглах заавар

1. Програмыг ажиллуулна.
2. `Row 1`-ээс `Row 9` хүртэл мөр бүрт зайгаар тусгаарласан 9 бүхэл тоо оруулна.
3. Програм шалгалтын үр дүнг харуулна.
4. `Check another Sudoku? (y/n)` гэсэн асуултад:
   - `y` — дахин Sudoku шалгана.
   - `n` — програмаас гарна.

## Тестийн тохиолдлууд

- **Зөв Sudoku:** бүх шалгалт `PASS`, эцсийн үр дүн `VALID` байна.
- **Буруу Sudoku:** давхардсан тоотой өгөгдөл оруулахад холбогдох шалгалт `FAIL`, эцсийн үр дүн `INVALID` байна.
