# Олон урсгалт Sudoku шалгах програм

## 1. Төслийн зорилго

Энэхүү төсөл нь Үйлдлийн системийн хичээлийн хүрээнд C хэл болон POSIX Threads (`pthread`) ашиглан 9×9 хэмжээтэй Sudoku шийдлийг шалгах програм юм.

Програм нь олон урсгал ашиглан Sudoku-ийн мөр, багана болон 3×3 дэд хүснэгтүүдийг зэрэг шалгана.

## 2. Үндсэн боломжууд

- 9×9 Sudoku хүснэгтэд тоон утга оруулах.
- 1–9-ийн хүрээнээс гадуурх болон хоосон нүдийг илрүүлэх.
- Мөр, багана, 3×3 дэд хүснэгтүүдийн давхардлыг шалгах.
- Шалгалтын үр дүнг `PASS` эсвэл `FAIL` гэж харуулах.
- Эцсийн үр дүнг `VALID` эсвэл `INVALID` гэж харуулах.
- 11 thread-ийн төлөвийг график интерфэйс дээр харуулах.
- Sudoku хүснэгтийг цэвэрлэж, дахин шалгах.
- Терминал дээр ажиллах хувилбарыг ашиглах.

## 3. Ашигласан технологи

- C програмчлалын хэл
- POSIX Threads (`pthread`)
- GTK3 график интерфэйс
- GCC хөрвүүлэгч
- MSYS2 UCRT64 орчин

## 4. Шаардлагатай орчин

Windows үйлдлийн систем дээр:

- MSYS2 UCRT64
- GCC
- GTK3
- `pthread` сан
- `pkg-config`

## 5. График интерфэйстэй хувилбарыг хөрвүүлэх

MSYS2 UCRT64 терминал нээгээд төслийн хавтас руу орно:

```bash
cd /c/OS-BD1/sudoku-validator
```

Дараа нь дараах командыг ажиллуулна:

```bash
gcc gui.c sudoku_core.c -o sudoku_gui.exe -pthread $(pkg-config --cflags --libs gtk+-3.0)
```

Програмыг ажиллуулах:

```bash
./sudoku_gui.exe
```

## 6. Терминалын хувилбарыг хөрвүүлэх

```bash
gcc -Wall -Wextra -pthread main.c -o sudoku_validator.exe
```

Ажиллуулах:

```bash
./sudoku_validator.exe
```

Терминалын хувилбарт мөр бүрд зайгаар тусгаарласан 9 бүхэл тоо оруулна.

## 7. График интерфэйсийг ашиглах заавар

1. Програмыг ажиллуулна.
2. Sudoku хүснэгтийн 81 нүдэнд 1–9 хүртэлх цифр оруулна.
3. `Шалгах` товчийг дарна.
4. Мөр, багана болон 3×3 дэд хүснэгтүүдийн үр дүнг шалгана.
5. `Цэвэрлэх` товчоор хүснэгт болон өмнөх үр дүнг арилгана.
6. `Заавар` товчоор ашиглах зааврыг нээнэ.

## 8. Тестийн тохиолдлууд

| Тест | Оролт | Хүлээгдэж буй үр дүн |
|---|---|---|
| Зөв Sudoku | Давхардалгүй зөв хүснэгт | Бүх шалгалт `PASS`, `VALID` |
| Хоосон нүд | Нэг нүдийг хоосон үлдээх | Алдааны мэдэгдэл |
| Буруу утга | `0` оруулах | 1–9 оруулахыг шаардах |
| Давхардсан тоо | Нэг мөрөнд ижил тоо оруулах | Холбогдох шалгалт `FAIL`, `INVALID` |
| Цэвэрлэх | `Цэвэрлэх` товч дарах | Нүд болон өмнөх үр дүн цэвэрлэгдэх |

## 9. Хиймэл оюуны хэрэглээ

Төслийн код боловсруулах, кодын ажиллагааг тайлбарлах болон баримтжуулалт бэлтгэхэд ChatGPT-ийн тусламж ашигласан.

## 10. Төслийн бүтэц

- `main.c` — терминалын хувилбар
- `gui.c` — график интерфэйс
- `sudoku_core.c` — Sudoku шалгах алгоритм болон thread-ийн төлөв
- `sudoku_core.h` — нийтлэг тодорхойлолт, функцийн зарлал
- `tests/` — тестийн тохиолдлуудын тайлбар
- `docs/` — гарын авлага болон screenshot
- `.github/workflows/build.yml` — GitHub Actions хөрвүүлэлтийн тохиргоо
